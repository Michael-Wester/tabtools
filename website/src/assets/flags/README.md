# Language selector flags

These square SVG flag assets are based on [flag-icons](https://github.com/lipis/flag-icons),
licensed under the MIT License. The upstream copyright and permission notice is
included in `LICENSE.flag-icons.txt`. The Spain and Serbia artwork is reduced to
its recognisable flag bands so the compact website asset remains small enough to
serve reliably.

The files are used locally by the TabTools website language selector. They are
clipped to circular controls by the site's CSS.
