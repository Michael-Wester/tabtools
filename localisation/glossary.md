# TabTools localisation glossary

The same concepts should use the following terms across the extension, website,
and store copy. Keep TabTools, browser names, URLs, domains, and user tab
titles unchanged.

| Source concept | Meaning to preserve |
| --- | --- |
| close tabs by site | Close every matching tab for a site, including the current tab, in regular windows |
| sort tabs by site | Reorder tabs in the current window, with sites having more open tabs first |
| close duplicates | Close repeated page URLs while leaving pinned tabs alone |
| inactive tabs | Tabs that meet the configured inactivity threshold; active, pinned, and audible tabs remain open |
| suggestions | Site chips generated from the user's local tab list |
| undo | Restore tabs closed by the currently open TabTools popup |
| local storage | Settings and cleanup statistics stored in the browser |
| browser store | The Chrome Web Store, Firefox Add-ons, or Microsoft Edge Add-ons destination |

Do not translate technical identifiers such as message keys, locale directory
codes, UTM parameters, or interpolation placeholders.
