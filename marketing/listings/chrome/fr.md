## Full description

Fermez les onglets par site, triez votre barre d’onglets et supprimez les doublons avec une extension gratuite et open source pour Chrome, Firefox et Edge.

Fermez ensemble les onglets d’un site: Ouvrez TabTools et cliquez sur un site dans Suggestions, ou faites un clic droit dans une page web et choisissez Fermer les onglets du site. Les onglets correspondants sont fermés dans toutes vos fenêtres normales, y compris l’onglet actuel.
Triez les onglets par site: Rapprochez les onglets d’un même site dans la fenêtre actuelle. Les sites ayant le plus d’onglets ouverts sont placés en premier.
Supprimez les onglets en double: Fermez les copies supplémentaires d’une même page en un clic. Les onglets épinglés restent en place.
Recherchez par mot-clé ou domaine: Saisissez un mot à rechercher dans les titres et les URL des onglets, ou un domaine exact comme youtube.com. Choisissez ensuite Fermer.
Fermez les onglets inactifs: Choisissez un délai d’inactivité dans les Paramètres, puis cliquez sur Inactifs pour fermer les onglets concernés. Les onglets actifs, épinglés ou diffusant du son restent ouverts.

L’extension TabTools traite les informations des onglets sur votre appareil. Les paramètres et les statistiques de nettoyage restent dans le stockage local du navigateur. L’extension n’utilise ni comptes, ni analyse d’usage, ni publicité, ni base de données externe.
