## Description (1451 characters)

Fermez les onglets d’un même site, triez-les par site et supprimez les doublons pour garder votre navigateur en ordre.

Ouvrez TabTools et cliquez sur un site dans Suggestions, ou faites un clic droit dans une page web et choisissez Fermer les onglets du site. Les onglets correspondants sont fermés dans toutes vos fenêtres normales, y compris l’onglet actuel.

Rapprochez les onglets d’un même site dans la fenêtre actuelle. Les sites ayant le plus d’onglets ouverts sont placés en premier.

Fermez les copies supplémentaires d’une même page en un clic. Les onglets épinglés restent en place.

Saisissez un mot à rechercher dans les titres et les URL des onglets, ou un domaine exact comme youtube.com. Choisissez ensuite Fermer.

Choisissez un délai d’inactivité dans les Paramètres, puis cliquez sur Inactifs pour fermer les onglets concernés. Les onglets actifs, épinglés ou diffusant du son restent ouverts.

Utilisez Annuler juste après avoir fermé des onglets depuis la fenêtre de TabTools, tant qu’elle est encore ouverte. Vous pouvez aussi rouvrir des pages depuis les onglets récemment fermés de votre navigateur.

Thèmes clair et sombre

Statistiques de nettoyage locales

L’extension TabTools traite les informations des onglets sur votre appareil. Les paramètres et les statistiques de nettoyage restent dans le stockage local du navigateur. L’extension n’utilise ni comptes, ni analyse d’usage, ni publicité, ni base de données externe.
