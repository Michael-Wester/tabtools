## Full description

Chrome, Firefox, Edge용 무료 오픈 소스 확장 프로그램으로 사이트별로 탭을 닫고, 탭 표시줄을 정렬하고, 중복 탭을 정리하세요.

같은 사이트의 탭을 한 번에 닫기: TabTools를 열고 추천 사이트에서 사이트를 클릭하거나, 웹페이지에서 마우스 오른쪽 버튼을 누르고 이 사이트의 탭 닫기를 선택하세요. 현재 탭을 포함해 모든 일반 창에서 해당 사이트의 탭이 닫힙니다.
사이트별로 탭 정렬: 현재 창에서 같은 사이트의 탭을 나란히 배치합니다. 열린 탭이 많은 사이트부터 앞에 놓입니다.
중복 탭 제거: 같은 페이지가 여러 개 열려 있다면 한 번의 클릭으로 중복 탭을 닫으세요. 고정된 탭은 그대로 유지됩니다.
키워드 또는 도메인으로 검색: 탭 제목과 URL에서 찾을 단어를 입력하거나 youtube.com과 같은 정확한 도메인을 입력한 뒤 닫기를 선택하세요.
비활성 탭 정리: 설정에서 비활성 기준 시간을 정한 뒤 비활성 탭을 클릭하면 조건에 맞는 탭이 닫힙니다. 활성 탭, 고정된 탭, 소리가 재생 중인 탭은 열린 상태로 유지됩니다.

TabTools 확장 프로그램은 기기에서 탭 정보를 처리합니다. 설정과 정리 통계는 브라우저의 로컬 저장소에 보관됩니다. 확장 프로그램에는 계정, 분석 추적, 광고, 외부 데이터베이스가 없습니다.

TabTools는 Chrome, Firefox, Microsoft Edge에서 사용할 수 있습니다. 컴퓨터에 추가하려면 이 페이지의 브라우저 링크로 해당 스토어를 여세요.
