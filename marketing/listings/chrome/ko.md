## Description (676 characters)

같은 웹사이트의 탭을 닫고, 사이트별로 정렬하고, 중복 탭을 제거해 브라우저를 깔끔하게 정리하세요.

TabTools를 열고 추천 사이트에서 사이트를 클릭하거나, 웹페이지에서 마우스 오른쪽 버튼을 누르고 이 사이트의 탭 닫기를 선택하세요. 현재 탭을 포함해 모든 일반 창에서 해당 사이트의 탭이 닫힙니다.

현재 창에서 같은 사이트의 탭을 나란히 배치합니다. 열린 탭이 많은 사이트부터 앞에 놓입니다.

같은 페이지가 여러 개 열려 있다면 한 번의 클릭으로 중복 탭을 닫으세요. 고정된 탭은 그대로 유지됩니다.

탭 제목과 URL에서 찾을 단어를 입력하거나 youtube.com과 같은 정확한 도메인을 입력한 뒤 닫기를 선택하세요.

설정에서 비활성 기준 시간을 정한 뒤 비활성 탭을 클릭하면 조건에 맞는 탭이 닫힙니다. 활성 탭, 고정된 탭, 소리가 재생 중인 탭은 열린 상태로 유지됩니다.

TabTools 팝업에서 탭을 닫은 직후, 팝업이 열려 있는 동안 실행 취소를 사용하세요. 브라우저의 최근에 닫은 탭 기능으로 페이지를 다시 열 수도 있습니다.
