## Full description

Închide filele după site, sortează bara de file și elimină duplicatele cu o extensie gratuită, cu sursă deschisă, pentru Chrome, Firefox și Edge.

Închide împreună filele unui site: Deschide TabTools și apasă pe un site din Sugestii, sau fă clic dreapta într-o pagină web și alege Închide filele site-ului. Se închid filele corespunzătoare din toate ferestrele obișnuite, inclusiv fila curentă.
Sortează filele după site: Așază alături filele aceluiași site în fereastra curentă, începând cu site-urile care au cele mai multe file deschise.
Elimină filele duplicate: Închide copiile suplimentare ale aceleiași pagini cu un clic. Filele fixate rămân pe loc.
Caută după cuvânt-cheie sau domeniu: Scrie un cuvânt pentru a căuta în titlurile și URL-urile filelor sau un domeniu exact, precum youtube.com. Apoi alege Închide.
Închide filele inactive: Alege un prag de inactivitate în Setări, apoi apasă pe Inactive pentru a închide filele care îndeplinesc condițiile. Filele active, fixate sau care redau sunet rămân deschise.

Extensia TabTools prelucrează informațiile despre file pe dispozitivul tău. Setările și statisticile de curățare rămân în stocarea locală a browserului. Extensia nu folosește conturi, analize de utilizare, reclame sau baze de date externe.

TabTools este disponibil pentru Chrome, Firefox și Microsoft Edge. Pentru a-l adăuga pe computer, folosește linkurile de pe această pagină pentru a deschide magazinul browserului potrivit.
