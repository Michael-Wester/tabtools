## Description (1346 characters)

Закрывайте вкладки одного сайта, сортируйте вкладки по сайтам и удаляйте дубликаты, чтобы поддерживать порядок в браузере.

Откройте TabTools и нажмите на сайт в разделе Предложения или щёлкните правой кнопкой мыши на веб-странице и выберите Закрыть вкладки сайта. Это закроет вкладки этого сайта во всех обычных окнах, включая текущую вкладку.

Расположите вкладки одного сайта рядом в текущем окне. Сайты с наибольшим числом открытых вкладок окажутся первыми.

Закройте лишние копии одной страницы одним нажатием. Закреплённые вкладки останутся на месте.

Введите слово для поиска в заголовках и URL вкладок или укажите точный домен, например youtube.com. Затем выберите «Закрыть».

Задайте порог времени бездействия в Настройках, затем нажмите «Неактивные», чтобы закрыть подходящие вкладки. Активные, закреплённые и воспроизводящие звук вкладки останутся открытыми.

Нажмите «Отменить» сразу после закрытия вкладок из всплывающего окна TabTools, пока оно ещё открыто. Также можно открыть страницы через список недавно закрытых вкладок браузера.
