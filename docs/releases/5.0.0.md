# TabTools 5.0.0

Release for Chrome, Firefox and Edge with a redesigned popup and safer cleanup
rules. It is assembled on the `release/5.0.0` branch from three pull requests:
the extension, the website and store listings, and the translations. These notes
cover the extension.

## Release notes

New popup:

- One list replaces the two-column grid: Inactive, Close duplicates, then every
  site with open tabs, most tabs first, with one tick mark per tab. Nothing is cut
  off after seven rows; a long list scrolls.
- The header shows how many tabs are open and on how many sites.
- Typing a keyword or a site lists the matching tabs, with the match marked,
  before anything closes. Enter or Close closes what is listed, and each row has
  its own close button.
- Inactive opens a list to review, with the time since each tab was last used.
  Nothing closes until Close is pressed. The time is set with a stepper, from
  30 minutes to 1 week.
- Settings gain a System theme that follows the browser, six accent colours, a
  Keep pinned tabs open switch and a Reset button for the closed count. The
  minimum-tabs setting is gone: every site is listed.
- The popup is 380 px wide in every language.

Changed behaviour:

- Close duplicates treats two tabs as copies only when their whole addresses
  match, including the part after `#`, so two Gmail conversations are no longer
  duplicates. A pinned copy, a copy playing sound and a copy in view always stay.
- Sort tabs leaves pinned tabs and tab groups where they are, and reports the
  number of tabs that moved.
- A tab that was in use until a moment ago is no longer listed as inactive. Chrome
  only reports when a tab came into view, so TabTools now notes when each tab is
  left. The note holds tab numbers and times, no addresses, and the browser clears
  it when it closes.
- Right-clicking in a private window no longer closes that site's tabs in normal
  windows.
- The background no longer wakes on every tab change, only when the user switches
  tabs, and it creates its menu item once per browser session.

Settings saved by 4.x still apply. A saved inactivity time shorter than 30 minutes
becomes 30 minutes. New installs, and people who never changed a setting, start on
the System theme. Anyone who changed a setting in 4.x keeps the Light or Dark theme
that was saved with it.

Undo still lasts only while the popup stays open. Permissions and minimum browser
versions are unchanged.

## Build and provenance

Use Node 22 from the committed release source:

```sh
npm ci
npm test
node build.js
node scripts/check-packages.js
```

`npm test` must pass without `TABTOOLS_PENDING_TRANSLATIONS`: every language has
to be complete and current before `release/5.0.0` is merged into `main`.

`PRIVACY.md` now describes the note of when tabs were left. Set its effective date
to the day of release.

Package each `dist/{chrome,firefox,edge}` directory with `manifest.json` at the ZIP
root. Record the exact source commit and SHA-256 of each archive. The Firefox
reviewer source archive must include build instructions. Keep existing tags and
release assets unchanged.

GitHub release publication, store submission and store approval/public availability
are separate outcomes. These notes do not assert that any has occurred.
