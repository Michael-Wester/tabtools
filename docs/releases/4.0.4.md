# TabTools 4.0.4

Patch release for Chrome, Firefox and Edge, based on the merged popup fix in
PR #36 (main commit `3f275dc92e9a1a7c0fc4f40acc42aa94c79eef6c`).

## Release notes

- Keep suggestions in two equal columns, with at most seven rows (14 suggestions,
  including Inactive when shown).
- Truncate long hostnames with an ellipsis while preserving the full hostname in
  tooltips and accessible button names.
- Preserve suggestion ranking, counts, keyboard navigation and right-to-left layouts.

This release excludes the unmerged built-in Chrome icons and Undo-copy changes.
Permissions, minimum browser versions and store listing text are unchanged.

## Build and provenance

Use Node 22 from the committed release source:

```sh
npm ci
npm test
node build.js
node scripts/check-packages.js
```

Package each `dist/{chrome,firefox,edge}` directory with `manifest.json` at the ZIP
root. Record the exact source commit and SHA-256 of each archive. The Firefox
reviewer source archive must include build instructions. Keep the existing
`v4.0.3` tag and release assets unchanged.

GitHub release publication, store submission and store approval/public availability
are separate outcomes. These notes do not assert that any has occurred.
